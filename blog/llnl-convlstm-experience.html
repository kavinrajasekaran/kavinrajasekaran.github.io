Building ConvLSTM U-Net for Amodal Video Prediction at LLNL

January 20, 2025 • 8 min read

During my Data Science Challenge internship at Lawrence Livermore National Laboratory in July 2025, I tackled one of the most fascinating problems in computer vision: predicting what objects look like behind occlusions in video sequences. This post walks through my journey building a ConvLSTM U-Net model that can "see through" occluded objects using only 2D convolutions.

The Challenge: Amodal Video Prediction

The problem I was tasked with solving was deceptively complex: given a video sequence where objects are partially occluded by other objects, can we predict what the hidden parts of those objects look like? This is called "amodal completion" – understanding the complete shape and appearance of objects even when they're partially hidden.

Traditional computer vision approaches struggle with this because they typically work frame-by-frame without leveraging temporal information. But objects move in predictable ways, and by analyzing motion patterns across multiple frames, we can make intelligent predictions about occluded regions.

Architecture Deep Dive: ConvLSTM U-Net

The heart of my solution was a hybrid architecture combining the spatial understanding of U-Net with the temporal modeling capabilities of ConvLSTM (Convolutional Long Short-Term Memory). Here's how it worked:

Spatial Encoding with U-Net

The U-Net architecture provided the spatial understanding needed to process each frame. With four encoder blocks (64, 128, 256, 512 channels), the model progressively extracted higher-level features while maintaining spatial resolution through skip connections.

Temporal Modeling with ConvLSTM

At each spatial scale, I integrated ConvLSTM cells to capture temporal dependencies. Unlike standard LSTM which works on 1D sequences, ConvLSTM maintains the 2D spatial structure while modeling temporal evolution. This was crucial for understanding how object motion reveals previously occluded regions.

# Core ConvLSTM cell implementation class ConvLSTMCell(nn.Module): def __init__(self, input_dim, hidden_dim, kernel_size, bias): super(ConvLSTMCell, self).__init__() self.conv = nn.Conv2d( in_channels=self.input_dim + self.hidden_dim, out_channels=4 * self.hidden_dim, # i, f, o, g gates kernel_size=self.kernel_size, padding=self.padding ) def forward(self, input_tensor, cur_state): h_cur, c_cur = cur_state combined = torch.cat([input_tensor, h_cur], dim=1) combined_conv = self.conv(combined) cc_i, cc_f, cc_o, cc_g = torch.split(combined_conv, self.hidden_dim, dim=1) i = torch.sigmoid(cc_i) # Input gate f = torch.sigmoid(cc_f) # Forget gate o = torch.sigmoid(cc_o) # Output gate g = torch.tanh(cc_g) # Candidate values c_next = f * c_cur + i * g h_next = o * torch.tanh(c_next) return h_next, c_next

Dataset Engineering: MOVi-MC-AC Scenes

One of the most challenging aspects was building a robust dataset loader for the MOVi-MC-AC (Multi-Object Video with Multi-Camera, Animation, Composition) dataset. This synthetic dataset contains complex scenes with multiple moving objects and varying occlusion patterns.

My custom dataset loader walked through five different scenes and assembled approximately 2,400 training sequences and 400 validation sequences per object. Each sequence contained 8 consecutive frames with corresponding:

  • RGB frames: The actual scene appearance
  • Amodal masks: Complete object boundaries (including hidden parts)
  • Modal masks: Visible object boundaries only
  • Segmentation data: Per-pixel object identification

The key insight was that the difference between amodal and modal masks revealed exactly which regions needed to be predicted – the hidden parts of objects that we couldn't directly observe.

Loss Function: Balancing Multiple Objectives

Designing the loss function was crucial for training success. I implemented a multi-component loss that balanced several objectives:

Spatial Losses

  • Amodal Loss (L1): Ensured accurate prediction within object boundaries
  • Background Loss (MSE): Kept background regions properly zeroed
  • Hidden Loss (L1): Focused specifically on occluded regions with higher weight

Temporal Consistency

To ensure smooth temporal evolution, I added a temporal consistency term that penalized abrupt changes in object appearance between consecutive frames within amodal regions.

Perceptual Quality with SSIM

The most innovative part was incorporating SSIM (Structural Similarity Index) loss with a learnable weight parameter. This helped maintain perceptual quality and realistic textures in predicted regions:

# Learnable SSIM weight with stability self.lambda_ssim_raw = nn.Parameter(torch.tensor(0.0)) @property def lambda_ssim(self): return F.softplus(self.lambda_ssim_raw) # Always positive # In loss computation ssim_val = self.ssim(pred_masked, gt_masked) ssim_loss = (1.0 - ssim_val) * self.lambda_ssim

Training Pipeline and Optimization

Training required careful optimization strategies. I trained for 20 epochs with automatic checkpoint saving, allowing me to resume training if needed. The mixed loss function meant balancing multiple competing objectives, which required gradient clipping to maintain stability.

One particularly challenging aspect was memory management – processing 8-frame video sequences with multiple channels quickly consumed GPU memory. I optimized batch sizes and implemented efficient data loading to maximize training throughput.

Evaluation and Debugging Tools

To ensure the model was learning effectively, I built comprehensive evaluation utilities:

Quantitative Metrics

  • PSNR (Peak Signal-to-Noise Ratio): Measured pixel-level accuracy
  • IoU (Intersection over Union): Evaluated object boundary prediction
  • Dice Score: Assessed segmentation quality

Visual Debugging

I created visualization tools that could export GIF and MP4 sequences showing:

  • Original video frames
  • Hidden regions (highlighted in red)
  • Ground truth amodal content
  • Model predictions

These visualizations were invaluable for debugging – I could immediately see when the model was hallucinating unrealistic content or failing to maintain temporal consistency.

Key Insights and Challenges

The Power of Temporal Context

The most significant insight was how much temporal information helps with amodal completion. Objects that seemed impossible to predict from a single frame became much clearer when considering their motion patterns across multiple frames.

Balancing Accuracy and Realism

Pure L1/L2 losses produced accurate but often blurry predictions. The SSIM component was crucial for generating realistic textures, but required careful tuning to avoid training instability.

Dataset Complexity

Working with synthetic data had advantages (perfect ground truth) and challenges (domain gap with real videos). The MOVi-MC-AC dataset's complexity meant long loading times and significant preprocessing requirements.

Results and Impact

The final model successfully learned to predict hidden object content with remarkable accuracy. Quantitative metrics showed significant improvement over baseline approaches, but more importantly, the qualitative results demonstrated coherent and realistic predictions that maintained temporal consistency across video sequences.

This work contributed to understanding how temporal information can be leveraged for challenging computer vision tasks, with potential applications in robotics, autonomous vehicles, and augmented reality systems.

Reflections on Research at LLNL

Working at Lawrence Livermore National Laboratory provided an incredible opportunity to tackle cutting-edge research problems with world-class computational resources. The interdisciplinary environment, combining computer vision, machine learning, and domain expertise, created the perfect setting for innovative research.

This project reinforced my passion for developing AI systems that can understand and reason about the visual world in sophisticated ways. The combination of theoretical understanding and practical implementation skills required made it one of the most rewarding research experiences of my career.
