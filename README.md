# Kavin Rajasekaran's Personal Website

This repository contains the source code for my personal website, which showcases my portfolio, publications, and blog.

## Features

- **Modern Design:** A clean and modern design with a focus on readability and user experience.
- **Responsive:** Fully responsive layout that works on all devices.
- **Light & Dark Mode:** Automatic theme switching based on your system preference.

## Built With

- HTML5
- CSS3
- No JavaScript
